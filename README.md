* **Networkwalks Hash Calculator**

* **Networkwalks Password Cracker**

# 🧪 Project Module 1 — Password Cracking with JTR

## 🔎 Introduction

**John the Ripper (JTR)** is a password security testing tool used by cybersecurity professionals to evaluate password strength. It supports different operating systems and various password and hash formats, including protected files such as PDFs, ZIP archives, and Office documents.

This module also introduces **Johnny**, the graphical interface for John the Ripper, which makes the process easier through a simple point-and-click interface.

### Tools Used

* John the Ripper

* Johnny GUI

* PDF Hash Extractor

* Notepad

* Windows PC / Kali Linux
